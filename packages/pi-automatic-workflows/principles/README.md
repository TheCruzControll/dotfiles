# Principles index

All 24 principles are context-sensitive guidance. Open a leaf when its use case is relevant; do not turn the whole catalog into mandatory steps. User instructions, permissions, and project trust boundaries take precedence.

- [`Attack the Premise`](./attack-the-premise.md) — Repeated fixes fail for the same reason.
- [`Boundary Discipline`](./boundary-discipline.md) — Parsing config, network, CLI, or framework input.
- [`Build the Lever`](./build-the-lever.md) — Bulk edits, analysis, migrations, or repeated checks.
- [`Encode Lessons in Structure`](./encode-lessons-in-structure.md) — A mistake or instruction repeats.
- [`Exhaust the Design Space`](./exhaust-the-design-space.md) — No established pattern fits a consequential design.
- [`Experience First`](./experience-first.md) — Product, UX, or API experience tradeoffs.
- [`Explain the Number`](./explain-the-number.md) — Performance, throughput, latency, or evaluation results.
- [`Fix Root Causes`](./fix-root-causes.md) — Debugging a symptom or recurring failure.
- [`Foundational Thinking`](./foundational-thinking.md) — Starting logic, schema, or a multi-phase change.
- [`Guard the Context Window`](./guard-the-context-window.md) — Long files, logs, transcripts, or broad fan-out.
- [`Laziness Protocol`](./laziness-protocol.md) — Refactoring, scope control, or abstraction pressure.
- [`Make Operations Idempotent`](./make-operations-idempotent.md) — Commands, loops, persistence, or crash recovery.
- [`Migrate Callers Then Delete Legacy APIs`](./migrate-callers-then-delete-legacy-apis.md) — Internal API simplification without external compatibility needs.
- [`Minimize Reader Load`](./minimize-reader-load.md) — Reviewing or shaping hard-to-follow code.
- [`Model the Domain`](./model-the-domain.md) — Stateful logic, branching, or repeated shape assumptions.
- [`Never Block on the Human`](./never-block-on-the-human.md) — A reversible choice tempts an unnecessary clarification.
- [`Outcome-Oriented Execution`](./outcome-oriented-execution.md) — Multi-phase migration or redesign.
- [`Prove It Works`](./prove-it-works.md) — Before declaring any task complete.
- [`Redesign From First Principles`](./redesign-from-first-principles.md) — Integrating a foundational new requirement.
- [`Separate Before Serializing Shared State`](./separate-before-serializing-shared-state.md) — Concurrent agents, tasks, or state mutations.
- [`Sequence Work into Verifiable Units`](./sequence-verifiable-units.md) — Sweeps, migrations, fixes, or stacked delivery.
- [`Subtract Before You Add`](./subtract-before-you-add.md) — Addition, rewrite, or refactor.
- [`Test Behavior, Not Implementation`](./test-behavior-not-implementation.md) — Writing or reviewing tests.
- [`Type System Discipline`](./type-system-discipline.md) — Typed API, schema, or state design.

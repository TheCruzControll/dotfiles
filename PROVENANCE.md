# Source provenance

This is a curated source snapshot, not an export of development sessions or whole
project directories. The owner confirmed permission to publish the locally created
code and modifications. No blanket license is assigned by this migration; upstream
licenses and notices continue to apply to their respective material.

- **pi-herdr-hybrid**: local modified checkout based on
  https://github.com/modem-dev/pi-herdr-subagents at
  `2489019ea678f0b7e3437727a0a5ca15d4cbe9c1`. Its original package manifest declares
  MIT and author Justin; that commit contains no root LICENSE file. Preserve the
  source attribution to HazAT/pi-interactive-subagents and
  ogulcancelik/pi-extensions. Agent/council adaptations from pi-subagents-herdr
  0.83.1 retain `LICENSE.pi-subagents` (Nico Bailon, MIT).
- **pi-automatic-workflows / Conductor**: local controller implementation plus
  pstack-derived workflow/principle content at revision
  `4dd1d05818d19792e7cd6e818f1667f95f7e1dbe`. The MIT notice is retained under
  `vendor/pstack/LICENSE`; see `CONTENT-README.md` for adaptation details.
- **pi-workflow-observer**, **pi-durable-handoff**, **pi-verified-workflows**:
  owner-approved local source. No separate upstream license was supplied.
  Verified Workflows tests now use a new synthetic source fixture rather than
  depending on an external course challenge directory. No challenge source is
  copied into this repository.
- **Caveman/Cavecrew and engineering skills**: installed copies from
  https://github.com/JuliusBrussee/caveman, including locally installed changes.
  The upstream Apache-2.0 license is retained in `skills/caveman/LICENSE`.
- **design skill**: locally configured skill and references.
- **herdr-agent-state.ts**: generated by Herdr integration version 9. Its managed
  header is retained; Herdr can overwrite it during integration updates.
- **RTK extension**: installed thin integration for https://github.com/rtk-ai/rtk;
  source comments retained. The RTK executable is installed separately.
- **Neovim**: local LazyVim-based configuration and lockfile. Its existing LICENSE
  is retained. Plugin source is installed separately from the pinned lockfile.
- **Published Pi packages and Ponytail**: installed separately, with versions or
  commit pinned in Pi settings; their source is not bundled here.

Unrelated root-level dotfiles predate this migration and are unchanged. Original
local project folders are intentionally retained on the source machine.
